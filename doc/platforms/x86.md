# x86 / x86_64

**Module:** `miraculix::x86` · **Toolchain:** stable · **Status:** most
complete platform.

**Probe:** `CPUID` (via `raw-cpuid`) and `XGETBV` for OS register state,
unioned with the compile-time target features. See
[detection](../detection-and-caching.md#what-detection-checks).

## Detect

| Item | Role |
|---|---|
| `detect_level() -> GenericLevel` | `V1..V4` (x86-64 psABI levels) |
| `detect_features() -> FeatureSet` | every ISA bit, cached |
| `warm_up()`, `detect_*_fresh()` | see [caching](../detection-and-caching.md) |
| `shortpath::verify_or_panic()` | startup guard for `target-cpu` builds |
| `Feature`, `FeatureSet` | one flag / bitset (`contains`, `contains_all`, `union`) |
| `GenericLevel::required_features()` | the flags each level needs |
| `Avx10` | AVX10 presence and version |
| `bundles::{V3, V4, V4Vbmi}` | every token of one level in one struct: `V3::detect()` then `v.avx2`, `v.fma`, ... |

## Auto slices: which tier runs

```
AVX-512F ─► AVX2 ─► AVX ─► SSE4.1 / SSSE3 / SSE2 ─► scalar
```

Specialised ops add their own rungs (VNNI, IFMA, BF16, FP16, VPOPCNTDQ,
BITALG, F16C, FMA). Each function's rustdoc lists its exact cascade
(`cargo doc --open`). FMA ops fall back to unfused AVX, then SSE, below FMA.

### Catalog

Call as `miraculix::x86::auto_up::NAME(...)` (alias `x86::auto`).

| Group | Calls | Meaning |
|---|---|---|
| Arithmetic | `add_*`, `sub_*` (`i/u 8..64`, `f16/32/64`) | `a ± b` (ints wrap) |
| | `mul_{i,u}{8,16,32}`, `mul_f{16,32,64}`, `mullo_{i,u}64` | `a * b` (low bits for ints) |
| | `div_f{16,32,64}`, `div_{i,u}32` | `a / b` (ints not vectorised; panic like `/`) |
| | `adds_{i,u}{8,16}`, `subs_{i,u}{8,16}` | saturating |
| | `abs_*`, `min_*`, `max_*`, `avg_u{8,16}` | `avg` = `(a + b + 1) / 2` |
| | `clamp_{i,u}{32,64}`, `clamp_f{32,64}` | `min(max(a, lo), hi)` |
| Bitwise | `and_*`, `or_*`, `xor_*`, `andnot_*` | `andnot` = `!a & b` |
| Compare | `cmpeq_*`, `cmpgt_*`, `cmplt_*`, `cmpge_*`, `cmple_*` | lane masks |
| Select | `select_{i,u}{8..64}`, `select_f{32,64}` | `mask != 0 ? b : a` (floats: sign bit) |
| Shifts | `shl_*` / `shr_*` / `sra_*::<IMM>`, `sllv_*` / `srlv_*` / `srav_*` | immediate / per-lane count |
| FMA | `fmadd_*`, `fmsub_*`, `fnmadd_*`, `fnmsub_*`, `fmaddsub_f16`, `fmsubadd_f16` | `±(a*b) ± c` |
| Convert | `f16_to_f32`, `f32_to_f16`, `bf16_to_f32`, `cvtneps_pbh_u16`, `cvtne2ps_pbh_u16` | half / bfloat16 |
| Dot / ML | `dpbf16_ps_f32`, `dpbusd_i32`, `dpbusds_i32`, `dpwssd_i32`, `dpwssds_i32` | BF16 / VNNI dot products |
| Integer | `popcnt_u{8,16,32,64}`, `madd52lo_u64`, `madd52hi_u64` | popcount, 52-bit IFMA |
| Xeon Phi | `p4fmadd_f32`, `p4fnmadd_f32`, `p4dpwssd_i32`, `p4dpwssds_i32` | `phi-asm` feature only |

Rules (lengths, wrapping, NaN): [slice-op rules](../cross-arch-semantics.md).

## Reductions

`x86::reduce` has `reduce_sum/max/min_f32`, `argmax_f32`, `topk_f32`,
`compress_gt_f32`, `exp_f32`, `logsumexp_f32`, `log_softmax_f32`, `dot_f32`,
`sliding_dot_f32`, `affine_u16_f32`, `lerp_u8`, `bf16_to_f32` and
`gemm_f32_kernel`, each with AVX-512F, AVX2+FMA, AVX2, AVX and SSE2 rungs.
A CPU without AVX2 still runs vector code.

Every function has a `*_with(tier, ..)` twin. Resolve `reduce::best_tier()`
once and pass it in to skip detection in a hot loop.

## Tokens

Layout follows the Intel Intrinsics Guide:

```
miraculix::x86::ops::
  mmx::
  sse::{sse, sse2, sse3, ssse3, sse41, sse42}
  avx::{avx, avx2, fma, f16c, avx_vnni, avx_vnni_int8, avx_vnni_int16,
        avx_ifma, avx_ne_convert, sha512, sm3, sm4}
  avx512::{avx512f, avx512bw, avx512cd, avx512dq, avx512vl, avx512vbmi,
           avx512vbmi2, avx512vnni, avx512ifma, avx512bitalg,
           avx512vpopcntdq, avx512bf16, avx512fp16, kmask, ...}
  avx10::fp8
  other::{aes, vaes, pclmulqdq, vpclmulqdq, sha, gfni, popcnt, rtm,
          sse4a, fma4, xop, amd3dnow}
```

Methods are `<op>_<type>x<lanes>` on arrays (`add_i32x8([i32; 8], [i32; 8])`).
Most `_slice` methods are crate-internal (they back `auto_up`); for whole
buffers use `auto_up`, or loop over fixed-width methods in a
[kernel macro](../kernel-macros.md).

AVX-512 has its own page: [AVX-512](avx512.md). Looking for a specific
intrinsic? [Op finder](../op-finder.md).
